# ログインなしで回答用リンクと管理用リンクの2本で運用する

アカウント管理をなくして、主催者も回答者もすぐ使えるようにするため、ログイン機能は作らない。日程調整の作成時に、回答用リンクと管理用リンクを発行する。管理用リンクを知っていることが、主催者である唯一の証明になる。

## Consequences

- 管理用リンクを紛失すると、復旧する手段はない。メール送信もしない(通知機能を持たない方針のため)。代わりに、作成直後の画面で保存を強く促す。
- 管理用リンクのトークンは、推測できない長さのランダム値(32バイト)にする。管理系の操作はすべて、サーバー側でトークンを照合する。
- 管理トークンと編集用トークンは、DB にはハッシュ値(SHA-256)だけを保存する。DB の中身が漏れても、管理用リンクと回答の編集権限は漏れない。トークンは総当たりできないランダム値なので、bcrypt のような遅いハッシュ関数は使わない。DB からトークンを取り出せないが、紛失したリンクは復旧しない方針なので失うものはない。
- 回答の編集はブラウザに保存した編集用トークンで行うため、別の端末からは自分の回答を編集できない。そのため同名の回答を許可し、古い回答は主催者が削除できるようにする。
- 後からログインを導入する場合、既存の日程調整の所有者をどう移行するかが課題になる。
