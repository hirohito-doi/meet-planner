# 候補はドラッグ1回で1件とし、完全一致だけを保存時にまとめる

候補を作る表では、マスを塗った結果から候補を組み立てる方式(When2meet 型)ではなく、1回のドラッグで候補が1件できる方式(Google カレンダー型)を採る。主催者が意図した区切りをそのまま候補にするためである。隣り合う候補や重なる候補も統合しない。候補の保存時に、開始日時と終了日時が両方とも完全に一致する候補だけを1件にまとめる。

## Consequences

- 19:00-20:00 と 20:00-21:00 を別々に作ると、19:00-21:00 にはならず、2件の候補として残る。
- 各日付の列では前日 18:00〜翌日 6:00 まで選べるため、異なる列から同じ日時の候補が作られることがある。これは保存時の重複判定でまとめる。列(日付)は候補の属性として持たない。
- 既存の候補と重複する候補を追加した場合は、既存の候補とその回答を残し、追加分を捨てる。
